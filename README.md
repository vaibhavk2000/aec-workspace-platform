# 🌐 AECWebService: Cloud CAD Drafting & Analytics Core

AECWebService is a microservice-driven SaaS architecture designed for interactive architectural design layouts, grid-snapped vector alignment processing, multi-layer engineering analysis, and student certification testing.

## 🚀 Instant Deployment Guide
1. Configure execution rules on the deployment script:
   ```bash
   chmod +x deploy.sh
   ```
2. Trigger the automated environment builder:
   ```bash
   ./deploy.sh
   ```
The application will bundle all runtimes and route incoming interface connections securely on Port `80`.
